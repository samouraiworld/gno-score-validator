How the score is built

Score = ( Test13-challenge + Score-test13 + Score-topaz + Score-sapphire ) / 4 + GitHub / 10, capped at 100

  • The four arenas carry equal weight: each contributes at most 25 points. GitHub is a bonus on top, worth at most 10 — it can lift a candidate, never sink one.
  • GitHub score = 25 × merged PRs + 8 × unmerged PRs + 5 × issues opened + 3 × commits + 2 × comment threads. A merged pull request is the only artefact proving code landed, so it outweighs intent and discussion.
  • Only contributions dated 2025 or later count toward the bonus. One candidate is affected: Santala-Research, whose three gnolang pull requests are typo fixes from 2023 that predate test13 entirely.
  • of the 98 candidates could be tied to a GitHub account, each verified by hand. A blank GitHub column is absence of evidence, not evidence of absence — it never costs points.
  • Fire drill is not scored yet and carries no weight. Adding it later means rebalancing the other four, or totals will run past 100.
